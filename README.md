## 🇬🇧 English

This skill produces brand promo short films from verified brand assets, product or website material, and a stated promotion goal. It starts by collecting the uploads and confirming the brief, then builds a brand fact table that locks down every usable brand fact. A source list comes next, so each claim in the film can be traced — product features are never invented. When authorization is missing, it will not counterfeit brand marks. From there it picks a story spine, plans precise beats, and directs the motion language so pacing and visual style land on every beat. Suited to new-product launches, official site showcases and social promotion.

### ✨ What it does

- Verified brand assets, product or site material plus a goal in → brand promo short film out
- Steps 1-2: collect uploads, confirm the brief, then build the brand fact table
- Step 3: create a source list so every claim in the film can be traced
- Never fabricates product features and never counterfeits brand marks without authorization
- Steps 4-5: choose a story spine and plan precise beats to control narrative pacing
- Step 6: direct the motion language so visual style lands on each beat
